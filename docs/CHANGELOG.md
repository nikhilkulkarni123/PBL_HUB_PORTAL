# Change Log

- HoD is the administrative role; no separate Admin role.
- One PBL Coordinator role assignment per semester.
- Enrollment-based team membership with same-semester and one-team constraints.
- Coordinator-configured team-size rules and guide capacity.
- Faculty project = faculty owner + faculty guide.
- Student-owned reserved project with guide-request workflow.
- Generic rubric designer with variable performance levels and CSV import.
- Student-wise rubric evaluation by project guide.
- Random temporary passwords, forced first-login change, HoD reset workflow and login throttling.
- Supplied faculty/student data prepared as seed data.
- HoD CSV master update screens.
