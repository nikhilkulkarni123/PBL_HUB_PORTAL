# Functional Operations — V2

## First installation
1. HoD loads Faculty and Student masters (initial seed already contains the supplied data).
2. HoD assigns one PBL Coordinator for each semester.
3. Coordinator verifies team size and guide capacity rules.
4. Coordinator creates teams from students in the same semester/PBL cycle.
5. Faculty publish project ideas; publishing faculty is owner and guide.
6. Student teams either apply to one faculty project or create one reserved team-owned project and request a guide.
7. Accepted allocation locks the team from other projects.
8. Coordinator creates reviews and rubrics and publishes them.
9. Project guides evaluate students against rubric descriptors and submit scores.

## Password operations
Initial and reset passwords are random temporary credentials. First-login change is mandatory. Forgot-password requests are resolved by HoD until reliable institutional email is available.

## Data updates
Use HoD CSV imports. Existing passwords are preserved. New users receive one-time temporary passwords.
