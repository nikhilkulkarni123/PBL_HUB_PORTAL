# Rubric Engine

A review owns one rubric. A rubric contains ordered criteria. Every criterion has a CO mapping, maximum marks, and any number of ordered performance levels. Each level stores a label, marks and descriptor.

The PBL Coordinator may design the rubric directly or import a CSV into the designer. Imported values are editable and must be reviewed before saving/publishing.

Faculty evaluation is student-wise within the guided team. For normal assessment the faculty chooses a performance level; the system derives marks. A zero-mark exception is stored separately so absence/non-eligibility is not misclassified as Level 1 performance.
